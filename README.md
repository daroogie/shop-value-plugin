# Shop Value Tooltip

A RuneLite plugin that displays dynamic shop buy and sell prices directly on item tooltips when trading with shop NPCs in Old School RuneScape.

## Features

* **Dynamic Price Calculations:** Automatically calculates buy and sell rates based on current shop stock levels.
* **Store Type Detection:** Distinguishes between General Stores (0.4% price decay rate) and Specialty Stores (3.0% price decay rate) dynamically.
* **Real-Time Stock Updates:** Reads current inventory levels directly from active shop container widgets on every frame tick.
* **Format Integration:** Displays values cleanly in gold-formatted Old School RuneScape
